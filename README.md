#📘 專案簡介

DyAlgo 是一套專為演算法教學設計的互動學習系統，整合 動態評量 (Dynamic Assessment) 與 體現式學習 (Embodied Learning) 策略，並透過 NFC 實體操作 搭配 大型語言模型 (LLM)，協助學習者深入理解 深度優先搜尋 (DFS) 與 廣度優先搜尋 (BFS) 兩大核心演算法。

系統能夠提供即時回饋、分級提示與歷程紀錄，解決傳統演算法教學中抽象難懂、缺乏個人化回饋的問題。
#✨ 功能特色

#🎓 演算法教學模組

支援 DFS 與 BFS 的模擬學習

可視化演算法流程與節點走訪順序

#🧩 體現式互動學習

利用 NFC 標籤模擬樹狀結構節點

學習者以實體操作模擬演算法步驟

#⚡ 動態評量機制

偵測錯誤操作並給予分級提示

引導學習者修正迷思概念

#🤖 AI 助教回饋

透過 LLM 生成個人化即時回饋

強化學習者的理解與反思

#☁️ 雲端資料追蹤

整合 Firebase，記錄學習歷程

提供教師與研究者後續分析

#📲 使用方式

啟動系統並登入。

選擇欲學習的演算法模式（DFS 或 BFS）。

使用 NFC 掃描節點進行演算法模擬。

系統會即時提供可視化流程與回饋。

若操作錯誤，系統會給予分級提示或 AI 助教建議。

學習紀錄將自動儲存至雲端，供教師或研究分析。
